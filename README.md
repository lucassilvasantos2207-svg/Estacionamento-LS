🚗 LS - Sistema de Estacionamento

Projeto de um sistema de gerenciamento de estacionamento desenvolvido com HTML, CSS e JavaScript.

A ideia desse projeto foi criar uma aplicação simples e funcional para controlar a entrada e saída de veículos, permitindo visualizar os carros estacionados, registrar saídas, calcular valores de permanência e acompanhar informações através de relatórios.

Durante o desenvolvimento, pratiquei conceitos importantes como manipulação do DOM, armazenamento de dados utilizando LocalStorage, criação de interfaces e organização de um sistema completo.

## ⚙️ Funcionalidades

- Cadastro de veículos
- Registro de entrada
- Visualização dos veículos estacionados
- Controle de saída de veículos
- Cálculo do valor de permanência
- Controle de vagas disponíveis
- Histórico de movimentações
- Relatório de faturamento

## 🛠️ Tecnologias utilizadas

- HTML5
- CSS3
- JavaScript
- LocalStorage
